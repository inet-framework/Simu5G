## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| externally-authored scene/SSOT → offline tool | The scenario JSON and any scene file are author-supplied input consumed by the Python tool. |
| offline tool → on-disk artifact | The tool produces files later parsed by the (untrusted-input-treating) C++ side in Plan 01-03/01-04. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Tampering | SSOT JSON parsed by precompute.py | mitigate | Validate required keys/types in `load_scenario`; raise on missing/typed-wrong fields before running RT. |
| T-01-02 | Tampering | request_hash misread as integrity guarantee | accept | request_hash is a cache/integrity key only, documented as NOT tamper protection (V6 N/A); C++ side re-asserts the full contract (Plan 01-03). |
| T-01-03 | Information Disclosure | bulk numeric table in JSON | mitigate | Bulk path-gain floats written only to LE binary + HDF5; JSON limited to small manifest scalars (CLAUDE.md constraint). |
| T-01-SC | Tampering | pip installs from requirements.txt | accept | No new packages installed this phase — venv pre-provisioned and pinned; RESEARCH Package Legitimacy Audit verdict OK for all. |
