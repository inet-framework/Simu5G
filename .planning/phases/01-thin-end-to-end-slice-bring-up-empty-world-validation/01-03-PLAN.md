<objective>
Implement the C++ consumer half of the walking skeleton: a `ManifestReader` that parses the JSON manifest and reads the little-endian binary path-gain table (with input validation), a `SionnaTable` holding the in-memory `[L]` gains, a `SionnaManager` that loads the artifact at `INITSTAGE_LOCAL` and fail-loudly asserts the manifest contract against the live scenario (CAL-02), and a `SionnaChannelModel::getAttenuation` override that returns the negated table path gain as dB attenuation while reusing all inherited `getSINR`/`getRSRP` machinery (MOD-01).
