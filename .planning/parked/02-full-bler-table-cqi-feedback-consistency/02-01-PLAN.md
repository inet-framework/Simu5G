<objective>
Widen the Phase-1 offline producer from a single-scalar path-gain table to a full per-MCS DL BLER
table. `precompute.py` gains a `compute_bler_table_dl` stage that calls `sionna.sys.PHYAbstraction`
(EESM default, shipped 5G-NR LDPC tables) once per link over DL MCS 2-27, writes `bler[L,M]` (MCS-primary keying per D-01) into a
new `bler.bin` (LE float64) and an HDF5 `/bler` dataset, and extends the manifest contract with the
new dimensions. Implements TOOL-04.

Purpose: This is the first vertical slice of Phase 2 — after this plan a researcher can run the
offline tool and get a finite, deterministic per-MCS BLER table in the artifact (offline end-to-end),
which every later C++ reader consumes. Honors D-03/D-04 (pinned `mcs_table_index=2`, MCS 2-27),
D-07 (EESM recorded as `sinr_effective_fun`), and the research correction that DL = `mcs_category=1`
(PDSCH) with MCS 0/1 returning the `inf` sentinel that MUST be rejected at write-time.

Output: extended `precompute.py`, extended `scenario.example.json`, new `test_bler_table.py` (RED-first).
</objective>
